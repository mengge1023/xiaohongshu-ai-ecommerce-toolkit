# 小红书爆款采集插件（生财专属版）

孟哥出品 · 基于大火箭 0.3.5，扩展版本 0.3.5.1。

1. 解压 ZIP，将整个文件夹保存在固定位置。
2. Chrome 116+ 打开 `chrome://extensions`，开启开发者模式，点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹。
3. 打开插件设置，填写自己的飞书多维表格分享链接与已启用的自定义授权码，点击“保存并连接”。支持 base / wiki 链接；首次识别知识库链接可能需要在飞书网页登录。
4. 打开小红书单篇笔记，点击分享按钮，等待保存完成。重复采集会新增记录，下一篇请等上一篇完成后再操作。

本版提供逐篇采集。没有新增自动遍历或批量抓取能力。

配置仅保存在本机浏览器，选定笔记与图片写入使用者自己的飞书表格。不要将授权码发给他人。

更新时可覆盖原目录内的文件，再到扩展管理页重新加载，并刷新已有小红书页面。保留原扩展身份，兼容已有飞书配置；如已安装原版，请覆盖升级或先停用原版，避免两个采集实例同时工作。浏览器使用默认扩展图标，请按完整名称识别。

安装包在配置和采集前进行本地完整性校验。如提示文件被修改，请重新取得完整的生财专属包。此版本仅为解压安装包。
