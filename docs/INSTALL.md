# 小红书AI电商爆单三件套 · 生财专属版

孟哥出品。如果感觉好用，欢迎到 GitHub 给我点个 Star。

## 1. 小红书 AI 文案大师

一键二创爆款文案，五种模式帮助你完成适合自己产品的小红书内容。

- 安装包：小红书AI文案大师-生财专属版-v1.2.1-scys.1.zip
- 解压并导入整个 `xiaohongshu-ai-copywriting-master` 文件夹；支持本地 Skill 的助手可使用。需要 Python 3.9+ 执行本地查重。
- 已安装同名技能时先备份并替换，保留用户目录下的 `.mengge-copywriting/` 历史，再新开对话。
- 使用：说“用小红书 AI 文案大师帮我改写这篇笔记”，按引导给出产品和参考素材。
- GitHub：https://github.com/mengge1023/xiaohongshu-ai-ecommerce-toolkit

## 2. 小红书爆品裁判

按“3标2源”检查候选产品，支持单品判断与 A/B 比较。

- 安装包：小红书爆品裁判-生财专属版-v1.3.1-scys.1.zip
- WorkBuddy 技能页上传该 ZIP，或导入解压后的 `xiaohongshu-product-selection` 文件夹；安装后新开任务。
- 使用：提供商品或笔记链接，采购价及采购运费由你提供。资料不足时会标注缺口，不编造评分。
- GitHub：https://github.com/mengge1023/xiaohongshu-ai-ecommerce-toolkit

## 3. 小红书爆款采集插件

将小红书单篇笔记、图片与互动数据保存到自己的飞书多维表格。

- 安装包：小红书爆款采集插件-生财专属版-v0.3.5.1.zip
- 解压并将文件夹留在固定位置。Chrome 116+ 打开 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，选中包含 `manifest.json` 的目录。
- 打开插件设置，填写自己的飞书表格链接及已启用的自定义授权码，然后“保存并连接”。
- 打开单篇小红书笔记，点击分享按钮，等保存完成再采下一篇。当前提供逐篇采集，不包含自动遍历批量抓取。
- 如已安装原版，请按包内说明覆盖升级或先停用旧实例，避免重复采集。浏览器使用默认扩展图标，按“生财专属版”名称识别。
- GitHub：https://github.com/mengge1023/xiaohongshu-ai-ecommerce-toolkit
