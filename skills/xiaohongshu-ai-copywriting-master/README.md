# 小红书AI文案大师（生财专属版）

孟哥出品 · 生财专属版。

一键二创爆款文案，五种模式帮助你把参考素材改写成适合自己产品的内容。

这是一个可安装到支持本地 Skill 和脚本执行的助手（如 WorkBuddy、Codex）的小红书文案 Skill。它把复杂提示词封装成引导式流程：学员选择写作模式，按提示提供产品和对标素材，AI 自动检查缺失信息并生成可供发布测试的笔记。具体宿主能否执行脚本须在安装后实际验证。

## 五种写作模式

1. **1:1 贴近仿写**：贴近对标笔记的结构、篇幅、节奏与情绪，替换非关键词表达。
2. **创新性写笔记**：保留成交逻辑与核心卖点，重做第一屏、场景、案例和信息组织。
3. **跨产品模仿**：抽象其他品类爆款的内容公式，再迁移到自己的产品。
4. **定题真人种草**：结合产品资料、同行爆款、已定封面和标题，默认生成 10 个标题与 3 篇不同切口的真人感种草笔记。

5. **场景化素人仿写**：根据原文生成约 180 字、三段式的日常场景文案；原文话题另附，不计字数或段落数。

## 主要能力

- 接收小红书笔记链接、完整文字或截图。
- 五种模式全部保留主原文话题：末尾话题区域逐字复制，保留顺序、大小写、重复项和间距，不删减、不改写、不新增。异品材料只借结构时，不替换主原文话题。
- 引导补充产品名称、材质/成分、真实卖点、目标人群与痛点。
- 尝试读取公开的 1688 商品页面并建立产品卡。
- 根据已经确定的封面和标题写正文，确保正文承接画面与标题承诺。
- 控制 AI 味、模板感和过强营销感，适量使用表情符号。
- 区分已确认事实、同源页面参考信息和待确认信息，避免编造成分、功效、销量或用户经历。
- 对洗护、美妆、食品、养生等品类规避绝对化、医疗化和未经证明的功效表达。

## 安装

将安装包解压后，在实际使用的助手中导入整个`xiaohongshu-ai-copywriting-master`文件夹。保留用户目录下已有的`.mengge-copywriting/`历史文件夹，新开一个对话使用新版。

### 安装生财专属包

1. 解压本 ZIP，保留完整的 `xiaohongshu-ai-copywriting-master` 文件夹。
2. 在支持本地 Skill 的助手中导入该文件夹，或将其放入 `~/.codex/skills/`。
3. 已装同名技能时先备份原文件夹，再替换；不要删除用户目录下的 `.mengge-copywriting/` 历史文件夹。
4. 新开对话，读取技能目录里的 `VERSION`，确认是 `1.2.1-scys.1`。

## 使用

在 Codex 中输入：

```text
使用 $xiaohongshu-ai-copywriting-master 帮我写小红书笔记
```

也可以直接指定模式：

```text
使用 $xiaohongshu-ai-copywriting-master 的第 4 种模式。
我是卖毛绒玩偶挂件的商家，这是我的 1688 链接……
```

AI 会根据当前信息逐步引导，不要求学员自己填写复杂提示词模板。

## 1688 链接说明

Skill 会优先尝试读取公开商品标题、属性、详情文字和可识别图片信息。部分 1688 分享短链可能受到登录、验证码、动态加载、站点安全策略或平台风控限制。

直链读取失败时，会尝试通过完整商品标题和货号查找公开索引或同源商品页面，并把信息分成：

- **已确认**：原商品页面或用户资料明确提供；
- **同源页面可参考**：其他平台同标题或同图商品显示，但尚未确认属于同一货源；
- **待学员确认**：材质、尺寸、填充物、价格、款式、授权和销量等无法核实的字段。

同源页面只用于辅助提问，不会被直接写成该商品事实。无法读取时，学员可以发送商品属性、主图和详情页截图。

## 输出与合规原则

- 不伪造个人体验、销量、认证、价格、库存或用户评价。
- 不将原料或成分直接等同于功效。
- 不承诺必爆、稳赚或确定性成交结果。
- 生成内容仍需使用者结合产品真实资料和平台最新规则进行最终审核。
- 1:1 仿写应尊重原创，不复制他人独有表达、经历、图片和品牌资产。
