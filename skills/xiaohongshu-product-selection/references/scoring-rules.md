# 评分规则

完整、未硬淘汰的商品按 100 分计：低粉 20、近期 20、24h 加购 15、累计销量 10、利润 20、素材 15。

| 项目 | 区间与分数 |
|---|---|
| 低粉 | ≤1000:20；1001–2000:17；2001–3000:14；3001–4000:11；4001–5000:8；>5000:0 |
| 近期 | ≤7天:20；8–30:16；31–60:10；61–90:5；>90:0 |
| 加购 | ≥500:15；300–499:12；200–299:7；<200:硬淘汰 |
| 销量 | <3000:10；3000–6999:9；7000–9999:7；10000–11000:3；>11000:硬淘汰 |
| 利润 | ≥50%:20；40–49.99%:18；30–39.99%:16；25–29.99%:12；<25%:当前货源不通过 |
| 素材 | A:15；B:10；C:0/不建议 |

等级：S 85–100（优先打）；A 70–84（可以打）；B 55–69（放宽打）；C <55（换品）。

AB 两方都通过时先比等级，再比总分。完全同分依次比较：对标粉丝更低、发布时间更近、24h 加购更高、累计销量距离 11000 更远、利润率更高、素材难度更低。
